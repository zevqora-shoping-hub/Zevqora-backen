# ZEVQORA

Production-ready e-commerce starter with:
- React + Vite frontend
- Node.js + Express backend
- Supabase-ready authentication/database
- Cashfree-ready payment architecture
- Cart, wishlist, orders, reviews, coupons
- Admin dashboard
- 100 seeded product records

## Run
Frontend:
```bash
cd frontend
npm install
npm run dev
```

Backend:
```bash
cd backend
npm install
npm run dev
```

Copy `.env.example` to `.env` in both apps.

Cashfree credentials are intentionally placeholders. Add real credentials only in your local/server environment.
